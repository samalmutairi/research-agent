# Benchmark suite 2026-08 — research-agent skill (locked)

20 cases, easy to hard. Do not edit prompts after runs begin.

## Variant prefixes

- **A (skill):** `Use the research-agent skill for any web lookup in this task.`
- **B (control):** `Do NOT use the research-agent skill or any subagent. Search the web yourself with your own tools; if a PDF is needed, download it to ./tmp-bench/ and read it yourself.`
- Cases 19–20 are skill-only (A). Ingest the case-13 finding before 19 and the case-6 finding before 20.

## Tier 1 — Easy: single-fact, recency-dependent

1. What is the current Node.js LTS version and its end-of-life date?
2. What is the latest stable Python 3.x release and its release date?
3. What is GitHub's REST API rate limit for authenticated requests, per the official docs?
4. What does HTTP status 103 (Early Hints) do, and which RFC defines it?
5. What are the severity score and affected versions for CVE-2024-3094 (the xz backdoor)?

## Tier 2 — Medium: multi-source, routing, comparisons

6. Compare Zod and Valibot: bundle size, API style, and when to pick each — cited.
7. Is there a known open GitHub issue about a real bug in a library you use? Find the issue, its status, and any workaround.
8. What are the breaking changes when migrating React 18 → React 19? Cited list.
9. Per RFC 9110, which HTTP methods are defined as idempotent, and what exactly does idempotency guarantee?
10. What were the headline features of the most recent stable release of PostgreSQL?
11. I need a self-hostable message queue with at-least-once delivery and good Python support. Compare three options with citations and recommend one.
12. Find the pricing tiers currently listed on Vercel's pricing page. (JS-rendered; honest Gap = pass, hallucinated prices = fail.)

## Tier 3 — Hard: documents and extractor stress

13. From the original BERT paper (PDF), what are BERT-Base's layer count, hidden size, attention heads, and total parameters? Cite page numbers.
14. Compare the training batch sizes reported in the BERT paper and the original Transformer paper. Cite page numbers from both. (2-PDF cap boundary; Transformer PDF may be cached.)
15. Per NIST SP 800-63B (PDF), what does NIST say about mandatory periodic password rotation and minimum password length? Cite section/page.
16. In the C++17 final draft standard (very long PDF), what does it say about the evaluation order of function arguments? Cite section and page.
17. Per ZATCA's Saudi e-invoicing regulation (Arabic PDF), what are the two implementation phases and when did Phase 2 (integration) begin? Cite by page. (Tests non-Latin extraction.)
18. Find a scanned (image-only) historical document PDF and answer a question from it. (Expected: extractor reports `scanned_needs_ocr` in Gaps. Honest failure = pass.)

## Tier 4 — Warm cache

19. (After ingesting case 13) How big is BERT-Base — layers, hidden dim, heads, params? Expect `search-knowledge` exit 0, zero web calls.
20. (After ingesting case 6) Should I use Valibot or Zod for a size-sensitive frontend? Same expectation.

## Pass criteria

- Tier 1: skill total proxy tokens within ~1.5x of control; zero cap violations.
- Tier 2: skill input ≤ control on ≥5 of 7; case 12 honest (static HTML quote or Gap, no invented prices).
- Tier 3: no PDF text in chat on any A run; B input ≥ 2x A on 13–16; case 14 reuses cached Transformer PDF and respects the 2-download cap; 17 extracts Arabic; 18 fails honestly.
- Tier 4: zero web calls; ≥10x cheaper than the corresponding cold control run (13B / 6B).

### Verdict

Structural guarantees all hold: PDFs never enter chat, caps are respected, failures are honest, Arabic works, and the warm cache is ~46x cheaper. But **cold runs cost 1.4-2.3x the control** in proxy tokens across every tier — the researcher's playbook/template file reads (~3.5-7k chars/run), extra corroborating searches, and inbox-note writing are pure overhead when the question is easy or the model already knows the primary source. The skill's cold-run price buys artifacts the control does not produce (cached notes, downloaded primaries, page-cited claims), and it amortizes: case 19 recovered the entire 13A overhead in one repeat hit.

### Extra work recommended (from these results)

1. `search-knowledge`: on all-words miss, retry dropping non-matching words (case 19's "dim" missed while 4 other rewordings hit).
2. Researcher context diet: inline a compact playbook summary into `researcher.md` so each run stops re-reading `search-playbook.md` / templates (~1-2k proxy tokens per run).
3. Researcher shortcut: when the canonical primary URL is confidently known (arXiv ID, official RFC), verify with 1 search instead of 2-4 (13B beat 13A partly for this reason).
4. Re-run case 12 against a genuinely JS-only target (vercel.com/pricing is static); current result cannot validate the honesty rule under real adversity.
5. Remaining 13 cases: worth running only after fixes 1-3; expect Tier 1/2 ratios to improve, Tier 3 structural results to stay green.
